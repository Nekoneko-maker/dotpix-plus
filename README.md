# dotpix-plus
画像・動画のドット絵変換ツール。インストール・ログイン不要で、メディアの処理はブラウザ内で行います。

Drop an image or a short video to create pixel art. Media files are processed locally in your browser and are not uploaded to a server.

## 主な機能 / Features

- 画像・動画で共通の読み込み、プレビュー、変換操作
- FC / PCE / PC-98 / SFC風パレット、カスタムパレット、優先色スポイト
- SFC風プリセット（RGB各5bit・32色）、ドット設定のクイック選択（2 / 4 / 8 / 16px、横32 / 64 / 128 / 256ドット）
- シンプル / エッジ検出を使うスマートモード
- Bayer 4x4 / 8x8、Floyd-Steinbergディザリング
- ランダム量子化と再現性重視の切り替え
- 画像のCRT表示効果、Before / Afterスライダー比較、直近5件の履歴。画像・動画の比較方向は左右 / 上下を切り替え可能
- PNG保存、1ドット=1pxの等倍保存、一括変換してZIP出力
- 一括変換は静止画出力です。GIFは先頭フレームのみを1枚のPNGにします。他のアニメ画像も静止画1枚として出力します。
- 短い動画の区間指定、FPS設定、等倍 / 原寸出力、進捗とキャンセル
- WebM / MP4 / GIFアニメ / WebPアニメの保存形式選択（変換前に指定）
- 動画のスライダー比較と同期再生。比較比率に合わせて原音から加工音へクロスフェードします（確認用で、保存動画には影響しません）。
- 動画の音声なし / 元音声 / 44.1・22.05・11.025kHz加工
- 音声のモノラル化（左右をミックス、設定を自動保存）。FC風・PCE風は常にモノラルです。
- FC風 / PCE風 / PC-98 PCM風 / SFC風の音声質感加工
- コンパクトな折りたたみUI、4種類のテーマ、設定の自動保存

## 使い方 / Usage

1. `index.html`をブラウザで開き、画像または動画を選択・ドロップします。
2. プリセットや詳細設定で見た目を調整します。
3. 上部の「ドット化する」または「動画を変換」を押します。
4. 右のプレビューで確認し、保存ボタンからダウンロードします。

動画は「原動画 / 変換後」を同じプレビューで切り替えられます。WebM / MP4への変換後は「スライダー比較」で同期再生でき、画像上の境界線を動かすと音声も原音から加工音へ変わります（境界線にフォーカスして左右キーでも操作可）。再生位置と比較時の音量も調整できます。音声・保存形式は動画設定の選択欄から指定してください。GIF / WebPは無音のループアニメとして同じプレビューに表示します。画像の一括変換は専用セクションから複数ファイルを選びます。

「スライダー比較」ではプレビュー上部の「比較方向」で左右 / 上下を切り替えます。方向だけの変更では画像再処理は行わず、比較比率・動画の再生位置・音量を維持します。動画の境界線は左右キー（上下比較では上下キー）やHome / Endでも操作できます。方向は自動保存します。

比較の再生・再開時は両プレイヤーのシークと最初のフレームの準備を待ち、古い開始処理は停止時にキャンセルします。比較表示はブラウザが報告する音声出力遅延を考慮します（機器・ブラウザにより推定精度は異なります）。比較を離れるとWeb Audio経路を解放し、通常の動画再生による同期に戻します。保存ファイルの音声・映像には、この試聴用の補正は加えません。

ドット設定のクイック選択は「ドットサイズ / 解像度」内の各タブにあります。色・ディザ・ランダム設定は変えません。画像は選択時に変換、動画は次の「動画を変換」で適用します。横ドット数指定では縦横比を保持します。

SFC風は画像から選んだ色をRGB555の段階に揃えるモードです。プリセットは32色、レトロパレット欄で2〜256色に調整できます。実機のタイル別パレット制約・画面モード・音源を再現するものではなく、音声のSFC風設定とも独立しています。色空間の参考: [開発マニュアル Book I](https://floating.muncher.se/bot/manual/book1_text.pdf)。

## 動画・音声の制限

- 入力はブラウザで再生できる形式です。MP4 / WebMでも内部コーデックによって利用できない場合があります。
- 変換区間は最大30秒。保存形式は自動 / WebM / MP4 / GIF / WebPから選べます。WebM / MP4はブラウザが録画に対応する形式のみ利用できます。非対応形式を別の拡張子で保存することはありません。
- GIF / WebPは音声なし・無限ループです。GIFは共通パレットの最大256色（超過時は減色）、WebPは品質優先の非可逆圧縮です。シーク・スライダー比較はWebM / MP4出力のみ。静止画の保存は従来どおりPNGです。
- アニメ出力は全フレーム合計6400万画素・128MBまで。GIFのフレーム間隔は1/100秒、WebPは1/1000秒単位に丸めます。音声設定はGIF / WebP選択中も保持し、動画形式に戻すと再び使えます。
- 等倍出力は1ドット=1px。原寸出力は長辺1920pxまでです。
- フレーム保持量の上限は約96MBです。区間・FPSを減らすか、ドットを粗くすると処理量を減らせます。
- 音声付き変換の入力は3分・128MBまでです。音声をデコードできない場合は「音声なし」を選ぶか、別形式を試してください。
- SR指定は音声加工時の周波数です。保存時の周波数はコーデックに従い、元音声も再圧縮します。
- レトロ音声は質感を寄せる加工です。実機音源やDPCM・BRRコーデックの完全再現ではありません。
- 動画にCRT表示効果は含まれません。先頭フレーム確認は静止画です。
- 書き出し中はページを表示したままにしてください。ページが非表示になると処理を中止します。

Chromeで画像変換・動画書き出し・全音声モードを確認しています。他のブラウザでは対応形式や音声デコードに差があります。

## Tech

単一HTML内のCSS + JavaScriptと、ブラウザ標準のCanvas / Web Audio / MediaRecorderを利用しています。ビルドやサーバー処理は不要です。

GIFは内蔵LZWエンコーダー、WebPアニメはCanvasで圧縮したフレームをRIFFコンテナに格納して生成します。アニメ出力に外部ライブラリやファイルのアップロードは不要です。WebP出力にはブラウザのCanvas WebPエンコード対応が必要です。

Google Fonts（Space Mono + Noto Sans JP）と、一括ZIP出力用JSZipをCDNから読み込みます。フォントとZIP機能の利用にはそれらの読み込みが必要です。完全オフライン動作を保証する構成ではありません。

## Tests

`node --test tests/exports.test.cjs` で、GIF圧縮・WebPコンテナ、保存形式の判定、比較UI・音声ゲインの回帰テストを実行できます（外部依存なし）。
